
# Railway Ticket Booking System

## Project Description
A web-based Railway Ticket Booking System developed using Python Flask, HTML, CSS and SQLite.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Features
1. User Registration
2. User Login
3. Train Search
4. Train Selection
5. Passenger Details
6. Ticket Booking
7. Booking Confirmation
8. My Bookings
9. Cancel Booking

## How to Run
1. Install Python.
2. Install dependencies using:
   pip install -r requirements.txt
3. Run the application:
   python app.py
4. Open http://127.0.0.1:5000

## Database
SQLite database is used to store user and booking details.

## Disclaimer
This is an academic demonstration project. It is not connected to IRCTC and does not provide actual railway reservations.
